# DevOps Learning Roadmap

A beginner roadmap I'll update as I practise.

## Phase 1 — Foundations
- [ ] Learn terminal basics and file paths
- [ ] Practise Git: status, add, commit, push, pull, branch, merge
- [ ] Learn GitHub repositories, issues, and README files
- [ ] Understand IP, DNS, HTTP/HTTPS, and ports

## Phase 2 — Linux and scripting
- [ ] Practise users, permissions, processes, packages, and logs
- [ ] Write small Bash scripts
- [ ] Learn Python basics and simple automation

## Phase 3 — Containers and CI/CD
- [ ] Understand Docker images, containers, ports, and volumes
- [ ] Create a basic GitHub Actions workflow
- [ ] Run automated checks on each push

## Phase 4 — Cloud and operations
- [ ] Learn cloud fundamentals and IAM basics
- [ ] Deploy a small demo application
- [ ] Practise monitoring, logs, and troubleshooting

**My rule:** build a small project for each phase instead of only watching tutorials.
